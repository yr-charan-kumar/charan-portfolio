# Y R Charan Kumar — Personal Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript. It presents skills, experience, projects, education, certifications, and contact links.

## Technologies
- HTML5
- CSS3
- JavaScript
- Google Fonts

## Features
- Responsive layout for desktop and mobile
- Light/dark theme toggle with saved preference
- About, skills, experience, projects, education, certifications, and contact sections
- Email, phone, LinkedIn, and GitHub links

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

No build tools are required.

## Deploy with GitHub Pages
1. Push these files to a public GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

Your site URL will generally be:
`https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/`

## Before publishing
- Confirm your GPA, education dates, internship details, certification details, and project descriptions.
- Confirm your email and phone number are the contact details you want to make public.
- Confirm the LinkedIn URL is correct and active.
- Add screenshots or project repository links if available.
